## Featured: Photo Frame Generator

A web tool I built for the **Crystal Open Scouts** frame campaign. Users upload a photo, place it inside the campaign frame and download the result as a profile picture.

- Drag to reposition and a slider to zoom, drawn live on an **HTML5 canvas**
- The photo is processed **entirely in the browser** and is never uploaded to a server
- One-click download of the finished image
- Frame artwork and interface designed by me, with Bangla typography

👉 [Try it live](https://tasnimulscout.github.io/tasnimul.hossain/frame.html)

## Built with

- HTML5, CSS3 and vanilla JavaScript (no frameworks)
- HTML5 Canvas for the frame tool and the interactive cursor effect
- Smooth page-to-page transitions
- Responsive layout for phones, tablets and desktops
